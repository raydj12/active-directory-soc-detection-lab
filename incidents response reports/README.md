# Selected Incident Reports

This folder contains selected incident reports from the RaeTech SOC lab.

Five detection scenarios were completed during the project. Rather than creating a full report for every detection, I selected two investigations that demonstrate different SOC analysis workflows.

## Incident 001 - Multiple Failed Logons

- Authentication investigation
- Windows Security Event IDs 4625 and 4624
- MITRE ATT&CK T1110 - Brute Force
- Final classification: Benign Positive - Suspicious But Expected

[View Incident 001](incident-001-multiple-failed-logons.md)

## Incident 004 - Network Service Scanning

- Network reconnaissance investigation
- Windows Security Event ID 5152
- Microsoft Sentinel analytics rule
- MITRE ATT&CK T1046 - Network Service Scanning
- Final classification: Benign Positive - Suspicious But Expected

[View Incident 004](incident-004-network-service-scanning.md)

The remaining detections and supporting evidence are documented in the main project README and detection sections.
